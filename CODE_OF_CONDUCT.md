# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and remember that many people here are learning. Questions
from beginners are welcome and should be answered with the same patience the tool tries to show.

Report unacceptable behavior to the maintainer through a private GitHub security advisory or the
contact listed on the maintainer's GitHub profile. Reports are handled confidentially.
